Introduction to Python

Python is a high-level, interpreted programming language.

It is widely used in web development, AI, automation, and data science.

Python emphasizes readability and simplicity.

print("Hello, World!")
  • Easy syntax
  • Open source
  • Large community support
Variables and Data Types

Variables store data values.

Python does not require explicit variable declaration.

Common data types include int, float, str, and bool.

x = 10 name = "Pratyush"
  • int → whole numbers
  • float → decimal numbers
  • str → text values
Control Structures

Control structures manage program flow.

Python uses indentation to define blocks.

if x > 5: print("Greater") for i in range(5): print(i)
  • if-else statements
  • for loops
  • while loops
Functions in Python

Functions allow reusable code.

They are defined using the def keyword.

def greet(name): return "Hello " + name

Functions can take parameters and return values.

Object Oriented Concepts

Python supports object-oriented programming.

Classes define blueprints for objects.

class Student: def __init__(self, name): self.name = name

Objects are instances of classes.
